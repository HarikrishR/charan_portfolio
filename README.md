# Charan — Film Director Portfolio

This is a single-page portfolio built with HTML, CSS, JavaScript and Bootstrap 5. It is a lightweight starter you can customize with your own content, images and contact details.

To preview locally:

1. Open `index.html` in your browser (double-click or use Live Server extension).

Optional: serve with a simple HTTP server:

```bash
# Python 3
python3 -m http.server 8000
# then open http://localhost:8000 in your browser
```

Files:
- `index.html` — main single-page app
- `css/style.css` — custom styles
- `js/main.js` — interactions and animations

Replace placeholder images and copy with your real content. Want me to customize the visuals, fonts, or copy next? Reply with your bio text and 3 project entries and I'll update the site.

Optimization & showreel
- The `assets/` folder contains SVG placeholders (small, vector-first) so the page loads quickly. Replace them with optimized JPEG/WEBP stills sized for the web (max-width 1600px) and use `loading="lazy"`.
- The site includes a responsive showreel modal. Replace the example YouTube ID in `js/main.js` with your showreel ID.
